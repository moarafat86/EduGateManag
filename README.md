# نظام إدارة بنود عقد البوابة الموحدة

ملف Excel لمتابعة بنود العقد ومخرجاته ودورات المراجعة، بيتبني بالكامل بسكريبت Python.
كل الأرقام في الملف معادلات، والسكريبت مش بيحسب أي رقم بنفسه.

## الشيتات

| الشيت | الغرض |
|---|---|
| دليل الاستخدام | طريقة العمل وشرح الحسابات |
| الإعدادات | بيانات العقد، نسبة الضريبة، مهلة المراجعة، الإجازة الأسبوعية، تاريخ الاحتساب |
| البنود | البنود التعاقدية + المسلّم والمقبول ونسبة الإنجاز والقيمة المتبقية |
| المخرجات | صف لكل مخرج + الحالة وأيام المراجعة والتأخير (محسوبة) |
| سجل المراجعات | كل حركة (تسليم / رد بملاحظات / قبول) في صف، مع حساب كل دورة |
| الأجازات | الأجازات الرسمية المستثناة من حساب الأيام |

## التشغيل

```bash
# بناء الملف من بيانات JSON
python builder/build_workbook.py data/sample.json output/EduGate_Contract_Sample.xlsx

# نقل البيانات من ملف المتابعة القديم (الناتج فيه بيانات حقيقية — لا ترفعه)
python builder/migrate_old.py Edu_Gate_Management_Sheet.xlsx data/real.json
python builder/build_workbook.py data/real.json output/EduGate_Contract_real.xlsx
```

المتطلبات: Python 3 و `openpyxl`. الملف بيستخدم `MINIFS` و`MAXIFS`، فمحتاج Excel 2019 أو Microsoft 365.

## نسخة المتصفح

`web/contract-tracker.html` تطبيق ويب بنفس الحسابات (حالة المخرج، دورات المراجعة، أيام التأخير، الإنجاز المالي)،
ومعاها بيانات الفوترة لكل مخرج، والمشاكل والقرارات، وطلبات التغيير، والتقرير الدوري،
منشور كـ Artifact على claude.ai والبيانات محفوظة في قاعدة بياناته (مش في الملف)، مع زرار تصدير Excel.
